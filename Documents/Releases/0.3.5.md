Apelin 0.3.5 shows how full a chat's context is beside what you type, keeps the model and effort controls inside the input box, lets each model's context window and output cap be set, and reads a command's output as the terminal wrote it.

- There was no telling how much of a chat's context was left until it stopped to compact. A ring at the end of the composer's model row now shows the share in use, turning orange past 75% and red past 90%, and a tap offers Compact Context… — the same confirmation the menu gives. It is faint and not tappable while the agent is running, and it appears once the agent has measured the chat.
- The model, reasoning effort and speed controls sat in a row of their own below the input box. They are now on the input's own ground, inside the box, with the context ring at their end.
- A provider sometimes reports a context window that is wrong for the model, so a chat compacted far too early or ran until the request failed. Settings ▸ Model Providers ▸ ⋯ ▸ Model Parameters sets the context window and the most a reply may be, per model; leave a field empty to use what the model reports. The agent compacts by the figure you set, and the ring draws it.
- A tool's result that carried terminal colour codes showed them as garbage in the trace. The escape sequences are dropped, and a result or any value given over several lines is set in a monospaced face so its columns line up.
