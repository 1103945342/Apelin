Apelin 0.3.4 is 0.3.3 unchanged, published by this fork's own pipeline: a push builds and tests it, and the release carries the packages that run built.

- No behaviour changed from 0.3.3. This version exists so the fork's own source has something to update to, and so every package it serves comes from a run that passed the host tests.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
