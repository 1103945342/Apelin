Luros 1.0.0 is Apelin's on-device IDE as a product of its own, installed beside Apelin, with a chat that can read and change GitHub issues and pull requests.

- Luros installs as `com.fluoxetine.luros`, with its own icon, data folder, URL scheme and background service, so one device can carry Luros and Apelin at the same time: neither package reads, replaces or removes the other's files.
- The development extensions, the device command-line tool icli, and the package daemon irisind with the installer it runs all travel inside Luros, so building a tweak or installing a package no longer needs another package first.
- Settings ▸ Environment ▸ Third-Party Tools now only reports ldid, git, dpkg-deb and uikittools, and offers the package that provides a missing one.
- Toolchains Luros sets up live under `usr/lib/luros/toolchains`, apart from Apelin's, so the same Command Line Tools can be installed by both without one package taking the other's files.
- Settings ▸ About is a page of its own: the icon, the slogan beneath it, then the version, the open-source licences and the logs.
- Two tools reach GitHub from a chat: `git_issue` lists and reads a repository's issues and can comment on, edit, close or reopen one, and `git_pull_request` lists and reads its pull requests and can open, merge, close or review one. Reading asks nobody; every change asks on a card that names exactly the call, once.
- A build's compile cache keys a product's own Swift sources on their bytes, so an edited source compiles again instead of linking the object compiled before it.

Requires iOS or iPadOS 16.0 or later and an A12 chip or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
