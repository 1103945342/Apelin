Apelin 0.4.5 opens a terminal and a file browser of its own, so neither Fila nor iGhostVT has to be installed.

- The chat's … menu opened a terminal in iGhostVT and a folder in Fila, and both apps had to be installed first. Open Terminal and Browse Files now open inside Apelin: a project's chat opens the project's folder, and General Chat opens that conversation's own temporary folder.
- A file's row in the files tab offered “Open in iGhostVT” on a long press. That item is now Open Terminal, which opens Apelin's terminal in the folder the file sits in; tapping a row still opens the file, or a folder, exactly as before.
- Settings ▸ SDKs and Toolchains showed an SDK's or a toolchain's folder by opening Fila. Browse Files now shows it in Apelin's own browser, which treats such a folder as a record: you can read it, it is not edited by hand, and it is removed with that page's Remove, which takes the record with the files.
- Apelin no longer depends on Fila or iGhostVT directly, so installing or updating it no longer needs either app.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
