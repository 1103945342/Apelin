Apelin 0.3.7 makes the plan pill switch when you tap it, opens the context panel on the first tap, and grows the input card again.

- The mode pill looked like a button and was wired like one, but the event it listened for only reaches a plain control when the system decides it is a button — on some versions it does not, and the pill never switched. The touch itself is listened for now, with a light tap of feedback, and the row relaid out the moment the word changes.
- The context ring needed two taps to show anything: the panel it opens started marked as open while publishing no height, so the first tap folded what was never there. It starts folded, and the first tap opens it.
- The ring is the way into what the context holds, whatever the chat is doing. It no longer refuses a tap while a run is going; only the Compact button inside the panel follows that.
- The camera button is gone from both the input card and the import panel. Photo, File and Web remain.
- The card grew again: a 60-point text band up to 168, a 44-point send and plus, a wider ring, and room around the text to match.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
